Шкала крепости KLINT

На банках KLINT используется понятная шкала крепости, которая помогает быстро сравнить вкусы внутри линейки.

Купить в розницуСотрудничать

Соответствие

  • 3/6 — 12 мг;
  • 4/6 — 16 мг;
  • 5/6 — 20 мг;
  • 6/6 — 25 мг;
  • 7/7 — 30 мг.

Как читать шкалу

Шкала нужна для быстрой навигации: мягче, баланс, сильнее. Подробности по каждому вкусу есть на страницах линейки.

Важно:

Материал носит информационный характер и предназначен только для совершеннолетних пользователей. Продукт содержит никотин.
